This is my latest project where I designed and modeled a connecting rod using SolidWorks. This project helped me strengthen my fundamentals in mechanical design and 3D modeling.

🔧 Project Highlights:

Created a fully defined 2D sketch with proper dimensions and constraints
Converted sketch into a 3D model using Extrude & Cut features
Applied Fillets and Chamfers for realistic geometry
Developed a complete assembly to understand part relationships
Generated engineering drawings with dimensions

🛠️ Tools & Features Used:

Sketching (Lines, Circles, Smart Dimensions)
Extruded Boss/Base & Extruded Cut
Fillet & Chamfer
Assembly Mates
Drawing Module

📚 Skills Gained:

3D Modeling & Parametric Design
Mechanical Component Understanding
Assembly Design Basics
Attention to Design Accuracy
CAD Workflow Optimization
